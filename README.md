# 🩸 Blood Bank Management System

A console-based Blood Bank Management System developed in **C++**.

The application allows hospitals or blood banks to manage donor records efficiently using file handling and basic data management techniques.

---

## Features

- Add New Donor
- View All Donors
- Search Donor by Name
- Search Donor by Blood Group
- Update Donor Information
- Delete Donor
- Blood Group Statistics
- Count Total Donors
- Automatic File Saving
- Automatic File Loading
- Duplicate Donor Detection
- Input Validation
- Colored Console Output

---

- STL
- File Handling
